# Aniverse Flip — стерео-карточки по аниме

Сайт-магазин: каталог карточек с вращением и переливом, конструктор своей карточки, форма заказа. Заказ уходит в Telegram через бота.

## Что внутри

- `site/` — сам сайт (HTML, CSS, JS, картинки, видео). Каталог, цены и контакты — в `site/data.js`.
- `serve.py` — сервер на чистом Python: отдаёт `site/` и принимает заказы на `POST /api/order`, пересылая их ботом в Telegram.

Статический хостинг (GitHub Pages и т. п.) не подойдёт: без `serve.py` заказы не будут отправляться.

## Запуск

```bash
python3 serve.py          # порт 8080
python3 serve.py 3000     # или свой порт
PORT=3000 python3 serve.py
```

Команда запуска для хостинга: `python3 serve.py` (порт берётся из переменной `PORT`, если хостинг её задаёт).

## Переменные окружения

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | id чата, куда приходят заказы |
| `PORT` | порт (необязательно, по умолчанию 8080) |

Локально их можно положить в файл `.env` (образец — `.env.example`). Файл `.env` в репозиторий не коммитится.

Бот не отвечает на сообщения — он только присылает заказы. Получатель должен один раз нажать у бота «Start», иначе Telegram не даст боту написать первым.
